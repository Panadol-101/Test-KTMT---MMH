## 💻 Cách 2: Chạy Offline trên máy tính

1. Tải toàn bộ mã nguồn về máy:
   - Bấm nút xanh lá **Code** ở góc trên -> Chọn **Download ZIP**.
   - Hoặc clone qua git:
     ```bash
     git clone https://github.com/Panadol-101/Test-KTMT---MMH.git
     ```
2. Giải nén (nếu tải ZIP).
3. Mở thư mục `KTMT-TNLuyenTap` và **click đúp vào file `index.html`** để mở bằng Chrome, Cốc Cốc, Edge hoặc Firefox.
